# Contribuer

Le projet est présenté publiquement sous le nom **Équipe Ma Voix Écrite**.
Contact privé : **mavoixecrite@proton.me**.

Les retours d’utilisateurs, proches, orthophonistes, ergothérapeutes et développeurs sont bienvenus. Les discussions et signalements GitHub sont publics : n’y publiez aucune donnée médicale, phrase privée, adresse personnelle, capture non anonymisée ou journal contenant un chemin utilisateur.

Avant un commit, utilisez le pseudonyme et l’adresse « noreply » fournie dans vos paramètres GitHub. Vérifiez aussi les métadonnées des images et documents. Ne publiez jamais de clé de signature, mot de passe, token, `local.properties`, cache ou dossier de compilation.

Les libellés des boutons principaux, le masquage du dernier message quand le clavier s’ouvre et la compatibilité téléphone/tablette font partie des points à préserver. Lancez les tests fournis avant de proposer une modification de comportement.
